
# 📰 Baldur Tech - Portal de Notícias

O **Baldur Tech** é um projeto de uma página de notícias estática, desenvolvida para praticar a estruturação de layouts complexos, o uso de containers e a estilização avançada com CSS.

## 🚀 Tecnologias Utilizadas
* **HTML5**: Estrutura semântica com o uso de `header`, `section`, `article` e `nav`.
* **CSS3**: Estilização personalizada, fontes, e gerenciamento de cores.
* **Flexbox**: Utilizado para criar o sistema de grid das notícias e o alinhamento do cabeçalho.

## 📋 Funcionalidades
* **Menu de Navegação**: Links internos que levam o usuário diretamente para as seções de Tecnologia ou Esportes.
* **Layout Responsivo (Base)**: Organização das notícias em colunas utilizando `flex-wrap`.
* **Diferenciação Visual**: Seções com cores de fundo distintas para facilitar a leitura e separação de temas.
* **Efeitos de Hover**: Interatividade nos botões de "Leia mais".

## 📂 Estrutura do Projeto
* `index.html`: Conteúdo e estrutura principal.
* `style.css`: Toda a lógica de design e posicionamento.
* `/source/img/`: Pasta contendo as mídias e imagens do portal.
